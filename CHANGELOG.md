# Changelog

## 1.0.0 — 2026-10-30

First public release, prepared for the **Open Source Higgsfield** challenge.

### Added

- Prompt-first studio UI for ComfyUI API workflows (image, video, audio).
- Model switcher, upload slots, grouped reference inputs, settings pills, sliders, switches, and conditional fields.
- Per-workflow Setup panel for model files.
- Generation gallery with preview, download, copy-inputs, and cleanup.
- Credit estimate for ComfyUI API/partner nodes with price badges.
- Workflow Manager: add, replace, rename, delete, and drag-and-drop import.
- Automatic ComfyUI launch on Windows, plus Studio-only and Linux/macOS launchers.
- Six local example workflows: Qwen Image 2.1, Krea 2, and MiniMax H3.
- Optional partner workflow example for OpenAI GPT Image 2.5.
- In-app `Naming Guide.html` and `docs/WORKFLOW_GUIDE.md`.
- Model list, demo script, submission checklist, GitHub upload guide, and troubleshooting docs.
- GitHub Actions check for Python syntax and workflow JSON validity.
