# Screenshots

Put real screenshots of Comfy Studio here. The README currently uses an illustration; `main.png` is the one to add first and swap in as the main image.

Suggested set:

| File | What to show |
| --- | --- |
| `main.png` | The full app with a finished result in the gallery |
| `composer.png` | The composer with a prompt, reference images, settings pills, and the Generate button |
| `manager.png` | The Manager with the workflow list and a Setup panel |
| `gallery.png` | A few image/video results |

## How to take a good screenshot

1. Open Comfy Studio at `http://127.0.0.1:7860`.
2. Generate one good SFW result.
3. Set the browser to 100–110% zoom.
4. Use `Win + Shift + S` on Windows, `Cmd + Shift + 4` on macOS, or your screenshot tool.
5. Crop out the browser chrome if you want a clean app shot.
6. Save as PNG. Keep it under ~1 MB if possible.
7. Do not include private information, API keys, or personal file paths.
