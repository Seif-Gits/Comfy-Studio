Comfy Studio Naming Guide

You tell Studio what to show by typing short marks into the titles of your nodes in ComfyUI. Double-click a node’s title, add the mark after the name, and export the workflow with Workflow → Export (API). Nothing else needs connecting.

A mark is always written in parentheses and starts with a keyword: (Input), (Switch), (Slider), (Setup), (Output) or (Credits). Capital letters don’t matter. One title can hold several marks.

1. The marks

MarkPut it onWhat the user gets
(Input)Any nodeEvery simple field of the node becomes a setting next to the model picker. Load Image / Audio / Video nodes become upload boxes, and the first text field becomes the prompt box.
(Switch)A node with a true/false fieldA toggle switch. It starts off, and off means “whatever the workflow says”. On sends the opposite.
(Slider min:0/max:10)A node with a number fieldA slider with the number shown live. Clicking the number lets the user type an exact value.
(Setup)Model, VAE, CLIP and LoRA loadersNot shown while generating. It appears under Manager → Setup so each person can pick the model files on their own computer. A missing or empty file is highlighted in red.
(Output)The Save nodeMarks the result. Its type (image, video or audio) decides which tab the workflow appears in.
(Credits)A closed-source (API) nodeMarks the workflow as a paid model. It gets a crown in the model list, and the Generate button shows the credits it will charge for the current settings, updated live as the user changes them. Write a number, (Credits 351.6), only if you want to fix the price by hand.

2. Add-ons

Write these inside the same parentheses, in any order, unless it says otherwise.

Add-onWhat it does
{Custom ratio}The name shown to the user instead of the field name. Don’t use parentheses inside the braces.
[1,3]Show only the 1st and 3rd field of the node. Fields are counted from the top, skipping the ones that have a wire connected. The settings appear in the order you list them.
optionalThe upload may stay empty. When it is empty, that node is switched off.
[image 2/10]A group of uploads that share one box. This node is slot 2 of 10. The first picture the user adds goes to slot 1, the next to slot 2, and so on, in the order the user drags them into. Works with image, audio and video.
min:0/max:10 step:2Limits for number fields. Works in (Slider) and in (Input), where typed numbers are kept inside the limits. Any of the three can be left out.
(2.Input)A number before the keyword sets the order. Numbered settings come first, in number order, then the rest in their usual order. The model picker always stays first.
{Custom ratio} on [1]A show rule. It is written outside the parentheses. Field 1 of this node only appears while the switch named “Custom ratio” is on. Use off to show it while the switch is off. Without [ ] the rule covers every field the node shows. A field that is hidden isn’t sent.

4. Good to know

  • Switches start off. Off always means the value saved in the workflow, whether that is true or false. To make “on” mean what you want, export the workflow with the opposite value.
  • Prompt. The first text field whose name doesn’t contain “negative” becomes the prompt box. Other text fields, such as a negative prompt, appear as settings.
  • Empty uploads. When an upload is empty, its node is switched off, and so is anything that can’t run without it. Studio decides on its own whether a box is “Required”. Writing optional forces it to be optional.
  • Seeds. Every field named seed or noise_seed gets a fresh random value on each run, even when you haven’t marked it.
  • Marked twice. If the same field is marked twice, for example (Input) (Switch {Custom ratio} [1]), it shows once, with the name you gave it.
  • Names with dots such as Qwen 2.1 work. Workflow names come from the file name, and you can change them under Manager → Rename.

5. Credits and the crown

Closed-source API nodes in ComfyUI carry a price formula, the same one that draws the “~351.6 credits/Run” badge on the node. Studio reads that formula from ComfyUI, works out the price for the exact settings and uploads the user has chosen, and shows it on the Generate button. It recalculates a moment after every change, so the number follows the sliders, drop-downs and added pictures. The total includes every API node that will actually run, and a price that varies shows as a range such as “120–350”.

  • Write (Credits) on the API node. Workflows with it get a crown 👑 in the model list, the model button and the Manager.
  • Studio also spots API nodes by itself, so a workflow still gets its price and crown if you forget the mark.
  • If a price can’t be worked out, the button says “uses credits”, and the terminal window prints which node and why. A very old ComfyUI may not provide price formulas at all. In that case use (Credits 351.6) to set a fixed price.
  • Credits are calculated as dollars × 211, the rate ComfyUI uses. If your rate differs, set COMFY_CREDITS_PER_USD before starting Studio.

6. If something looks wrong

  • Open Manager. A workflow without an (Output) node is rejected, and a field number that doesn’t exist is listed in red under that workflow.
  • A red ⚠ Setup needed button next to the model picker means a model file is empty or not found. Click it to fix it.
  • Re-uploading a workflow with the same file name replaces the old one and keeps its Setup choices.
