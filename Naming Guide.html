Workflow Naming Guide

Comfy Studio turns a normal ComfyUI API workflow into an app by reading node titles. Rename the nodes you want to expose, export the workflow with Workflow → Export (API), and upload the JSON in Manager.

Important

Use the API export, not the regular UI workflow. The API file is a flat map of node IDs. The UI file contains a "nodes" array and Studio will reject it with a helpful message.

The five-minute version

In ComfyUI, rename these nodes:

Prompt                  →  Prompt (Input)
Load Image              →  Load Image (Input optional [Image 1/10])
Resolution Selector     →  Resolution Selector (Input [1,2])
Duration                →  Duration (Input {Seconds})
Steps                   →  Steps (Slider {Steps} [2] min:1/max:50 step:1)
Custom ratio            →  Custom ratio (Switch {Custom ratio} [1])
Model loader            →  Model (Setup)
Save Image              →  Save Image (Output)

Export the API workflow and upload it. The app now has a prompt box, a 10-image reference strip, resolution controls, a duration field, a slider, a toggle, a Setup entry, and an image result card.

Marker reference

A marker is a parenthesised instruction in a node title. A title can contain several markers and rules.

MarkerWhat it does
(Output)Marks a node whose result appears in the gallery. At least one output is required.
(Input)Exposes the node's literal fields as app controls.
(2.Input)Sets the order in the composer. Numbered inputs come first.
(Input [1,3])Exposes only fields 1 and 3 of that node (counted from 1).
(Input {Label})Renames the field or group in the app.
(Input optional)Makes a media input optional; the branch is disabled when it is empty.
(Input optional [Image 1/10])Creates one grouped strip of 10 image slots.
(Switch {Name} [1])Exposes a boolean field as a named toggle.
(Slider {Name} [2] min:0/max:10 step:1)Renders a numeric field as a slider with limits.
(Setup)Moves model-file choices into Manager → Setup.
(Credits 351.6)Sets a fixed credit price when no price badge is available.

Visibility rules

Rules hide fields while a named switch is on or off. Put the rule in the same node title as the fields it controls. The bracket is a list of field positions on that same node; leave it out to apply the rule to every exposed field on the node.

Preset (Input [1]) {custom ratio} off [1]
Custom width (Input [1]) {custom ratio} on [1]

The switch itself is a separate boolean node:

Custom ratio (Switch {Custom ratio} [1])

One node can carry several rules:

Resolution Selector (1.Input [1]) (2.Input [2]) {custom ratio} off [1] {custom ratio} on [2]

This shows field 1 while the switch is off, and field 2 while it is on. Hidden fields are not sent with the generation request.

Grouped media inputs

Use the same group name and kind on every member:

Load Image (Input optional [Image 1/10])
Load Image (Input optional [Image 2/10])
...
Load Image (Input optional [Image 10/10])

The syntax is [<group name> <position>/<max>]. The kind comes from the loader class. The group becomes one growing, drag-to-reorder strip in the composer. Leave out optional to make the group required.

Setup fields

Use (Setup) for model files, VAEs, text encoders, and LoRAs. These are chosen once in Manager → Setup and saved in setup/<workflow>.json.

Load Diffusion Model (Setup)
Load CLIP (Setup)
Load VAE (Setup)
Load LoRA (Setup)

Studio validates the choices against ComfyUI's available files and shows “Setup needed” when something is missing.

Supported output classes

  • Images: SaveImage, PreviewImage, SaveAnimatedWEBP, SaveAnimatedPNG
  • Video: SaveVideo, VHS_VideoCombine
  • Audio: SaveAudio, SaveAudioMP3, SaveAudioOpus, PreviewAudio

Any node with (Output) is treated as an output. Unknown classes fall back to image, or to video/audio when the class name contains those words.

Common mistakes

Message / symptomFix
“Not an API workflow.”Use Workflow → Export (API), not the normal export.
“No node titled ‘(Output)’.”Rename your save or preview node, e.g. Save Image (Output).
“Setup needed.”Open Manager → Setup and choose an installed model file.
A field is missing.It may be linked to another node, or skipped by [1,3]. Check the field order.
A switch does not hide anything.Put the rule in the same node title and match the switch name exactly.
Generate stays disabled.A required media input is empty, or the workflow has no prompt. Add the input or mark it optional.
An upload is ignored.The loader class must be supported. Add custom classes to MEDIA in studio.py.

Before you upload

  • The workflow runs end-to-end in ComfyUI.
  • At least one node is marked (Output).
  • Model loaders are marked (Setup), not exposed as free text.
  • Optional media inputs are marked optional.
  • Grouped media uses the same group name and kind on every member.
  • Switch names in rules match the (Switch {Name} …) exactly.

Tip: upload the same filename to replace a workflow. Your saved Setup choices are kept.
