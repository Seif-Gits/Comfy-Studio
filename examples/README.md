# Examples

This folder is for **example outputs** and prompt ideas. The app itself does not read this folder; it is here so people can see what the workflows can make before running them.

## What to add

- 1–3 images made with Qwen Image 2.1 or Krea 2.
- 1 short video made with MiniMax H3 (5–10 seconds is enough).
- A short note for each: the prompt, the workflow, and the main settings.

Suggested layout:

```text
examples/
├── README.md
├── prompts.md
├── qwen-portrait.png
├── krea-product.png
├── minimax-cafe.mp4
└── partner-workflows/
    ├── README.md
    └── GPT_2.5.json
```

## Rules

- Keep everything **SFW**.
- Do not use celebrity faces, copyrighted characters, film stills, or other unlicensed likenesses.
- Keep files small. GitHub’s web uploader has a 25 MB per-file limit, and the repo should stay easy to clone.
- Compress video to H.264 MP4, 720p or 1080p, short duration.
- You can link a full-quality video on YouTube instead of committing it.
